# Учебный локальный канал поверх Диффи–Хеллмана

Сетевой сценарий использует два процесса на localhost: они генерируют новые параметры и закрытые простые показатели, выполняют DH, затем обмениваются несколькими зашифрованными сообщениями в одном соединении. Ключи для направлений выводятся из общего секрета через HKDF, сообщения защищаются ChaCha20-Poly1305. Учебное условие предполагает канал без подмены; проверку подлинности участников здесь не добавляем, чтобы не вводить заранее доверенные ключи или сертификаты. Поэтому сценарий демонстрирует обмен и обработку сообщений, но не защищает от активной атаки «человек посередине».
