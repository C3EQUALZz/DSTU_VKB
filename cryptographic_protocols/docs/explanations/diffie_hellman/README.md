# Диффи–Хеллман: лабораторная работа и канал связи

Крейт `diffie_hellman` содержит тест Рабина–Миллера, генерацию больших простых чисел, поиск первообразных корней и обмен ключами. Команды `serve` и `connect` запускают **два отдельных процесса**: они вычисляют общий секрет, выводят из него ключи для двух направлений и обмениваются зашифрованными сообщениями по TCP на localhost.

## Быстрый запуск в двух терминалах

В корне репозитория сначала соберите программу:

```bash
cargo build --release -p diffie_hellman
```

В **первом терминале** запустите сервер. Он напечатает `сервер ожидает подключения` и останется ждать клиента:

```bash
cargo run --release -p diffie_hellman -- serve --once
```

В **другом терминале** запустите клиент и передайте два сообщения:

```bash
cargo run --release -p diffie_hellman -- connect \
  --message 'Привет, Боб!' \
  --message 'Канал работает'
```

Сервер сгенерирует новое простое `p = 2q + 1`, первообразный корень `g` и собственный закрытый простой показатель. Клиент проверит параметры и создаст свой закрытый простой показатель. Оба процесса обменяются только открытыми значениями. Затем сервер получит два зашифрованных сообщения, преобразует текст в верхний регистр и вернёт зашифрованные ответы. Клиент выведет:

```text
Ответ сервера: ПРИВЕТ, БОБ!
Ответ сервера: КАНАЛ РАБОТАЕТ
```

Флаг `--once` завершает сервер после этого сеанса. Без него сервер остаётся ждать следующих клиентов; для каждого нового соединения он генерирует новые параметры и секреты.

## Ввод с клавиатуры

Запустите сервер как выше, а клиент — без `--message`:

```bash
cargo run --release -p diffie_hellman -- connect
```

После приглашения `Введите сообщение` набирайте по одной строке и нажимайте Enter. Соединение сохраняется для следующих строк. Введите `/quit` или завершите стандартный ввод, чтобы закрыть сеанс. Если нужен другой локальный порт, задайте **один и тот же адрес** обеим сторонам: `serve --bind 127.0.0.1:9000` и `connect --addr 127.0.0.1:9000`. Запуск на внешнем сетевом интерфейсе намеренно отключён.

## Что видно в журналах

Обе стороны пишут этапы обмена, открытые параметры и значения, номера зашифрованных сообщений, получение и обработку текста. Закрытые показатели и общий секрет в журнал не попадают. По умолчанию подробности Рабина–Миллера тоже выводятся на уровне `INFO`. Для короткого журнала сетевого опыта задайте одинаковый фильтр в обоих терминалах:

```bash
RUST_LOG=diffie_hellman::application=info,diffie_hellman::presentation=info,diffie_hellman::domain=warn \
  cargo run --release -p diffie_hellman -- serve --once
```

Для клиента замените `serve --once` на `connect --message 'Привет, Боб!'`. Содержимое сообщения видно участникам и попадает в их учебные журналы; не отправляйте таким способом секретные данные.

Это **учебный канал без проверки подлинности участников**. Методичка предполагает отсутствие подмены в исходном канале. TCP такого свойства не даёт, поэтому активный посредник может подменить обмен. 128-битный модуль по умолчанию удовлетворяет учебному требованию `p > 2^64`, но не предназначен для защиты реальной связи. В сетевых командах `--seed` запрещён, чтобы не делать закрытые показатели предсказуемыми.

## Остальные команды задания

```bash
# 128-битное простое, число попыток и время:
cargo run --release -p diffie_hellman -- gen-prime --bits 128 --rounds 32

# Все простые в полуоткрытом диапазоне [1000; 1100):
cargo run --release -p diffie_hellman -- range-primes --from 1000 --to 1100

# Первые 100 первообразных корней по простому модулю 1009:
cargo run --release -p diffie_hellman -- roots --n 1009 --count 100

# Однопроцессный пример из методички: p=97, g=5, общий секрет K=75:
cargo run --release -p diffie_hellman -- dh --n 97 --g 5 --xa 36 --xb 58

# Автоматически сгенерировать большое p и два больших простых показателя:
cargo run --release -p diffie_hellman -- dh --bits 128 --rounds 32
```

Команда `dh` — ручная математическая демонстрация: она считает обе стороны внутри одного процесса и показывает оба закрытых показателя. Для двух процессов используйте `serve`/`connect`. Флаг `--seed 42` допустим только в однопроцессных командах, когда требуется повторить числовой пример.

## Отчёты и проверка

Сохранить вывод двух процессов и числовые примеры, затем собрать оба отчёта:

```bash
cargo build --release -p diffie_hellman
python3 scripts/diffie_hellman/capture.py
python3 scripts/diffie_hellman/build.py --year 2025
python3 scripts/diffie_hellman/build.py --year 2026
```

Результаты лежат в `artifacts/diffie_hellman/`, отчёты — в `docs/reports/2025/diffie_hellman/` и `docs/reports/2026/diffie_hellman/`. На титульных листах указана группа **ВКБ53**. Проверка кода: `just ci`.
