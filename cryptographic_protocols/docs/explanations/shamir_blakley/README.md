# Схемы Шамира и Блэкли — варианты 1–20

По расписанию это лабораторная работа №3. Исходное задание находится в лабораторной №5 методических указаний 2026 года, страницы 109–125. В таблице 5.1 на страницах 116–124 приведены 20 вариантов; личный вариант 11 находится на странице 120.

Нужно восстановить слово по схемам Шамира и Блэкли при пороге `k = 3` и общем числе долей `n = 5`. Методичка требует выполнить восстановление отдельно по трём и пяти долям. Программа содержит исходные доли **всех 20 вариантов**; по умолчанию запускается вариант 11. Отчёт подготовлен только для него.

## Запуск

Из корня `cryptographic_protocols`:

```bash
# Личный вариант 11: обе схемы, сначала три, затем пять долей
cargo run -p shamir_blakley --

# Другой вариант из таблицы 5.1
cargo run -p shamir_blakley -- --variant 12

# Одна схема и выбранное число долей
cargo run -p shamir_blakley -- --variant 7 --method shamir --shares 3
cargo run -p shamir_blakley -- --variant 20 --method blakley --shares 5

# Собственный набор долей из JSON (пример восстанавливает КОТ)
cargo run -p shamir_blakley -- --input crates/shamir_blakley/examples/custom_kot.json
```

Для вывода без служебного журнала можно указать `RUST_LOG=off` перед командой. При обычном запуске `INFO` показывает этапы решения системы.

Вариант 11 даёт коды `197 213 200 196 205 192` и слово **ЕХИДНА**; вариант 12 — **ЕДИНЫЙ**. Таблица приложения Б методички названа ASCII, но русский блок соответствует Windows-1251 (`192 = А`, `197 = Е` и т. д.).

## Данные вариантов и свой JSON

Исходные числа находятся в `crates/shamir_blakley/data/variants.json`. Они извлечены из таблицы 5.1 скриптом `scripts/shamir_blakley/extract_variants.py` и проверены восстановлением обоими методами по трём и пяти долям для всех 20 вариантов. Для повторного извлечения нужен `pdftotext`.

Флаг `--input FILE` принимает один объект того же формата, что элемент массива `variants` в файле данных. Поле `number` необязательно. Схема формата:

```json
{
  "number": 21,
  "shamir": { "x": [1, 2, 3, 4, 5], "values": [[209, 222, 241, 266, 297]] },
  "blakley": {
    "coefficients": [[7, 23, 1], [27, 8, 15], [25, 10, 13], [1, 21, 30]],
    "values": [[1584, 5645, 5237, 619, 3505]]
  }
}
```

Каждая внутренняя строка `values` — один символ и ровно пять долей. Число строк в обеих схемах должно совпадать. Полный рабочий пример на три символа — `crates/shamir_blakley/examples/custom_kot.json`. `--input` и `--variant` взаимоисключающие.

## Что вычисляется

- Шамир: из каждой выбранной доли `(xᵢ, yᵢ)` составляется строка матрицы Вандермонда. Для трёх долей решается система для `S, b, a` в `f(x) = ax² + bx + S`; для пяти решается система для пяти коэффициентов, после чего проверяется, что коэффициенты при `x³` и `x⁴` равны нулю.
- Блэкли: каждая доля задаёт уравнение `a₁S + a₂u + a₃v = y`. Для трёх долей ищется точка пересечения трёх плоскостей; для пяти решается переопределённая система из всех пяти уравнений. Противоречивые доли вызывают ошибку.
- Все вычисления выполняются с целыми числами произвольной длины и сокращёнными рациональными дробями. Округления и модуля `p` нет: методичка не задаёт конечное поле.

Для варианта 11 получается `f(x) = 5x² + 9x + S` и точка `(S, 5, 8)`. В других вариантах коэффициенты и координаты могут отличаться. Значение `S` преобразуется в заглавную русскую букву по приложению Б; поддерживаются коды `192..223`.
