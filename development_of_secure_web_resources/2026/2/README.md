## Локальный запуск

```sh
uv sync --frozen
uv run blast-furnace run --port 5002
```

Открыть <http://127.0.0.1:5002>. Python 3.14; PyCharm: `.venv/bin/python`.
Docker для выполнения и проверки ЛР2 не используется.

## Формула и контрольные значения

`Тг = 2405 + 0,75 × (Тд − 1200) − 5,40 × Wд + 43 × (w − 21) − 52 × Vпг`.

Диапазоны: Тд 900–1300 °C; Wд 1–40 г/м³; w 21–35 %;
Vпг 0–15 м³/100 м³. Поддерживаются дроби с точкой или запятой.
Неверный ввод возвращает форму с HTTP 400 и сообщением, без записи в журнал.

| Тд | Wд | w | Vпг | Тг, °C |
|---|---|---|---|---|
| 1000 | 10 | 21 | 0 | 2201,0 |
| 1200 | 15 | 25 | 8 | 2080,0 |
| 1100 | 20 | 23 | 5 | 2048,0 |
| 1300 | 1 | 35 | 0 | 3076,6 |

## Структура и журнал

- `src/blast_furnace/domain/services/calculations.py` — независимая формула.
- `domain/temperature.py` — параметры и допустимые диапазоны.
- `application/calculate_temperature.py` — сценарий расчёта и порт журнала.
- `infrastructure/calculation_log.py` — дописывание UTF-8 файла с блокировкой.
- `presentation/http/routes.py` — GET/POST и преобразование строк формы.
- `presentation/http/templates/tempr.html` — форма, результат, экранирование Jinja.
- `setup/` — конфигурация, фабрика и внедрение зависимостей.
- `tests/` — модульные и интеграционные проверки.
- `docs/` — отчёт ЛР2, протокол проверок и снимки экрана.

Пакет `domain/services` выполняет роль `services` из методички в src-структуре ЛР1.
Контроллер находится в `presentation/http/routes.py`. Контракты проверяет import-linter.

Журнал создаётся в `static/calc_log.txt` относительно каталога запуска.
Путь меняется переменной `CALC_LOG_PATH`; каталог создаётся при первой записи.
Журнал не раздаётся через HTTP: статические ресурсы Blueprint расположены отдельно.
Переносы строк в комментариях экранируются: одна запись занимает одну строку.
При ошибке записи возвращается HTTP 503 без сообщения об успешном сохранении.
Комментарий ограничен 500 символами.

```sh
uv sync --frozen --group report
uv run --group report python tools/capture_pages.py --url http://127.0.0.1:5002
uv run --group report python tools/build_report.py
```

Для снимков нужно запущенное приложение. DOCX и PDF создаёт `tools/build_report.py`;
для PDF используется локальный Chrome. Конфигурации Docker унаследованы от ЛР1
и дополнены томом журнала; сборка и запуск Docker для ЛР2 не выполнялись.
