# Лабораторная работа № 2 — классы и объекты

Выполнил: Ковалев Данил Петрович, ВКБ53.

- `main.py`: ограниченная по вместимости колония бактерий.
- `task2.py`: независимые корзины и проверка запрещённых названий грибов.
- `test_lab2.py`: 12 автоматических тестов на стандартном `unittest`.

Запуск из текущего каталога (проверено на Python 3.9.6; сторонние пакеты не нужны):

```sh
python3 main.py
python3 task2.py
python3 -m unittest -v test_lab2
```

Вместимость колонии предполагается целым неотрицательным числом; состояние изменяется через методы. Названия грибов сравниваются точно с `Мухомор` и `Поганка`, как в прекоде.

Подробный отчёт: [Ковалев Д.П. ВКБ53 ЛР2.docx](docs/Ковалев%20Д.П.%20ВКБ53%20ЛР2.docx).
Фактический протокол запусков и тестов: [verification.txt](docs/verification.txt).
