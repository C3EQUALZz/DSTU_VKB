# SecureDev

Справочник и приложение для расчётов доменной плавки с доступом по учётным записям.

## Термины

**Режим дутья** — набор из температуры, влажности, содержания кислорода и расхода природного газа для одного расчёта.

**Теоретическая температура горения (ТТГ, Тг)** — температура горения в горне доменной печи, рассчитанная для заданного режима дутья.

**Сравнение режимов** — расчёт ТТГ для двух наборов параметров с определением разницы «второй режим минус первый».

**Учётная запись** — зарегистрированный пользователь SecureDev с уникальным именем, адресом электронной почты и паролем.

**Сеанс доступа** — право пользоваться закрытыми страницами после регистрации или входа. Действует до выхода или в течение часа с момента входа.
