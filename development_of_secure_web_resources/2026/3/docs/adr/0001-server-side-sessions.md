# Серверные сессии с отзывом при выходе

После переноса данных сессии из cookie в SQLite приложение может прекратить действие конкретного сеанса при выходе. Подписанная cookie Flask содержит случайный идентификатор, а таблица `sessions` связывает его хеш с учётной записью и временем создания. Проверка БД на запросе требует доступного хранилища и позволяет сохранить часовой предел даже между перезапусками приложения.
