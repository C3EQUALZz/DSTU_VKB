# English Presentation

Термины учебной презентации и материалов для подготовки к выступлению.

## Language

**Presentation / Презентация**:
Набор ровно из 12 слайдов на английском языке, охватывающий одну выбранную тему.

**Speaker script / Текст выступления**:
Отдельный текст для устного сопровождения каждого слайда на английском языке уровня B2 с русским переводом в том же DOCX. Выступление рассчитано на 10–12 минут.

**Research section / Исследовательская часть**:
Часть презентации, в которой анализируются опубликованные исследования и практические примеры RAG. Она не является собственным экспериментом докладчика.

**Grammar coverage / Грамматическое покрытие**:
Наличие в английском тексте действительного и страдательного залога, инфинитива, герундия, причастия, сложного существительного и сложного дополнения.

**Retrieval-Augmented Generation (RAG)**:
Подход к генерации ответов, при котором найденные во внешней базе знаний материалы добавляются в контекст языковой модели.

**Baseline RAG / Базовый RAG**:
Простой вариант RAG с заранее определённым процессом поиска фрагментов и генерации ответа.

**GraphRAG**:
Семейство подходов к RAG, использующих графовые структуры знаний. По сообщению пользователя GraphRAG входил в его CI-модуль; Microsoft GraphRAG используется как внешний исследовательский пример, без предположения, что пользователь применял именно его реализацию.

**Agentic RAG**:
Подход к RAG, в котором агент выбирает действия поиска или обработки информации и может выполнять несколько шагов в зависимости от запроса и промежуточных результатов. По сообщению пользователя Agentic RAG также входил в его CI-модуль.

**AI-assisted static analysis / Статический анализ с помощью ИИ**:
Анализ исходного кода с участием языковой модели для поиска потенциальных уязвимостей без выполнения анализируемой программы.

**CI security module / Модуль анализа безопасности в CI**:
Написанный пользователем программный модуль, который сканирует кодовую базу на потенциальные уязвимости и использует RAG, GraphRAG и Agentic RAG с материалами OWASP и другими источниками.

**AG2**:
Фреймворк для организации взаимодействия агентов, включаемый в описание стека по указанию пользователя. Версия и конкретный API личного проекта не установлены.

**FastMCP**:
Python-фреймворк для создания MCP-серверов и клиентов, включаемый в описание стека по указанию пользователя. Он предоставляет доступ к инструментам и ресурсам и сам по себе не является алгоритмом RAG.

**Retrieval failure rate / Доля ошибок поиска**:
Доля релевантных материалов, не найденных при заданном числе возвращаемых результатов. В выбранном эксперименте Anthropic используется 1 − recall@20; это не доля неверных итоговых ответов.

**Illustrative cost model / Иллюстративная модель затрат**:
Расчёт по явно указанным допущениям для объяснения структуры расходов. Он не является измеренной экономией реальной компании или актуальным тарифом поставщика.
