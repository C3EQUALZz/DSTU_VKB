# Visual direction: RAG in cybersecurity

Статус: предложение для презентации, подготовленное по реально просмотренным примерам NVIDIA, Google DeepMind и Microsoft RAGHack. Подробности и ссылки: [research/DESIGN-REFERENCES.md](research/DESIGN-REFERENCES.md).

## Визуальная система

- Формат 16:9.
- Основной фон `0B1220`, фон отдельных областей `142035`, основной текст `F7FAFC`, вторичный текст `B9C6D8`.
- Цвет найденных доказательств — cyan `39D0D8`; системных этапов — blue `6F91E8`; ограничений и важных оговорок — amber `F5C76A`.
- Совместимые шрифты: Arial для текста, Courier New для кода. Заголовки 34–42 pt, основной текст 20–24 pt, подписи схем преимущественно от 18 pt. Подписи источников компактнее, но не заменяют собой основной текст.
- Все видимые слова, подписи таблиц, осей, схем, комментарии к коду и скриншоты на английском.
- Сквозной визуальный принцип: путь от документов через поиск к ответу с доказательствами. Графические связи используются для объяснения реальных отношений, а не как фоновый декор.
- Разные композиции для схемы, кейса, графика, сравнительной таблицы и вывода; одинаковые карточки на всех слайдах не используются.

## Научные результаты и скриншоты

- Графики по данным исследований редактируемые в PowerPoint, с точными значениями, единицами и источником.
- Два количественных примера: метрика поиска Anthropic и стоимость токенов Microsoft dynamic GraphRAG. Условия экспериментов видны рядом с выводами.
- Настоящие скриншоты первоисточников сохраняют оригинальные цвета и английские подписи. Скачанные рисунки первоисточников не называются скриншотами браузера.
- Скриншот личного проекта включается только при наличии реального проекта и подходящего материала. Иначе используется явно обозначенная схема проектируемого решения.

## Анимации

- Плавные переходы Fade между слайдами, без автоматического перелистывания.
- На объясняющих схемах отдельные этапы появляются по клику в порядке рассказа.
- Агентный цикл раскрывается пошагово; повторение показывается один раз, без бесконечной анимации.
- График и таблица остаются читаемыми в конечном статическом состоянии; анимация не прячет источник и методику.
- Число слайдов остаётся равным 12: анимации не имитируются дублированием страниц.
- Ожидаемый способ реализации проверяется по первичной документации; наличие анимаций в файле и их воспроизведение проверяются отдельно.

## Код

- Два коротких сниппета: базовый RAG и агентный цикл с ограничением шагов.
- Ориентир 5–7 строк каждый, крупный моноширинный текст и умеренная подсветка.
- Если код упрощён, подпись **Illustrative pseudocode** обязательна.
- Подробное объяснение выносится в текст выступления, чтобы слайд оставался понятным аудитории с английским B2.

## DOCX для печати

- Бумага A4, белый фон, тёмный текст, поля для обычной печати.
- Для каждого слайда: номер, английское название, английский текст выступления, затем русский перевод.
- Пометки о раскрытии схем по клику входят в сценарий.
- Приложения: грамматическая карта с примерами и номерами слайдов, словарь терминов, источники.
