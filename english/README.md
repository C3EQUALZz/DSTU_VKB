# RAG for Secure Code

Автор: **Ковалев Данил, группа ВКБ53** / **Danil Kovalev, Group VKB53**.

## Итоговые файлы

- [Презентация PPTX](output/RAG_for_Secure_Code.pptx) — 12 английских слайдов, редактируемые диаграммы и таблица, схемы, скриншоты, примеры кода и штатные анимации PowerPoint.
- [Презентация PDF](output/RAG_for_Secure_Code.pdf) — статическая версия с раскрытыми схемами.
- [Текст выступления DOCX](output/RAG_Speaking_Notes_EN_RU.docx) — английский текст по каждому слайду, русский перевод, подсказки для показа, грамматическая памятка, словарь и источники.
- [Текст выступления PDF](output/RAG_Speaking_Notes_EN_RU.pdf) — печатная версия на 16 страницах, экспортированная самим Word.

Выступление рассчитано на **10–12 минут**, уровень английского **B2**. Сценарий содержит **1277 английских слов**. Русский перевод предназначен для подготовки и не входит в устное английское выступление.

## Как показывать

Открой итоговый PPTX в настольном Microsoft PowerPoint и запусти показ. На объясняющих слайдах этапы раскрываются по клику. Между слайдами используются короткие Fade-переходы. PDF показывает конечное статическое состояние и подходит для просмотра или печати.

## Содержание и источники

Основа — личный CI-модуль для статического анализа исходного кода, описанный автором: RAG, GraphRAG, Agentic RAG, AG2 и FastMCP. Подробные схемы упрощены для объяснения. Числовые результаты относятся к исследованиям Vul-RAG и Microsoft и имеют отдельные подписи; это не показатели личного модуля.

Исследовательские заметки находятся в [research](research). Основные файлы сборки: [src/content.json](src/content.json), [src/build.cjs](src/build.cjs), [src/capture.cjs](src/capture.cjs). Подтверждённые требования: [PRESENTATION-BRIEF.md](PRESENTATION-BRIEF.md).

## Проверка

Проверены число слайдов, язык, автор и группа, все семь грамматических конструкций и целостность OOXML. Просмотрены все 12 слайдов после экспорта самим PowerPoint и все 16 страниц документа после экспорта самим Word. Отдельно проверены исправленные скриншоты, переносы и связи схем. Показ анимаций проверен в PowerPoint на слайдах 4 и 8. Итоговая проверка файлов записана в [output/verification.json](output/verification.json).

## Повторная сборка

`npm ci` устанавливает зависимости из lock-файла; `node src/build.cjs` создаёт базовый PPTX и DOCX. `node src/office.cjs` создаёт скрипт `src/office.applescript`; запуск `osascript src/office.applescript` добавляет штатные эффекты через установленный PowerPoint и сохраняет итоговые PPTX/PDF.

Для печатного PDF текста: `node src/office-helper-word.cjs`, затем `osascript src/office-helper-word.applescript`. Нужен установленный Word; если он запросит доступ, выбирай только папку `output` этого проекта. Подробности проверки: [research/OFFICE-RUNTIME.md](research/OFFICE-RUNTIME.md).

Не подменяй итоговый PPTX базовой сборкой: в базовой версии ещё нет штатных эффектов. Диагностические экспорты и сгенерированные AppleScript-файлы исключены из Git.

Использованные навыки: [Anthropic PPTX](https://github.com/anthropics/skills/blob/main/skills/pptx/SKILL.md), [Anthropic DOCX](https://github.com/anthropics/skills/blob/main/skills/docx/SKILL.md). Первичные источники и полные ссылки включены в документ выступления.
