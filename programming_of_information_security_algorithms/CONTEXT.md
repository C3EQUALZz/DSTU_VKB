# Арифметика эллиптических кривых

Термины практической работы «Калькулятор на эллиптических кривых».

## Language

**Кривая над простым полем**:
Множество решений y² = x³ + ax + b по простому модулю p > 3 вместе с точкой на бесконечности; 4a³ + 27b² ≠ 0 по модулю p.
_Avoid_: эллипс, график над вещественными числами

**Точка на бесконечности O**:
Нейтральный элемент группы точек: P + O = P.
_Avoid_: ошибка вычисления, неопределённая точка

**Противоположная точка**:
Для P = (x, y) точка −P = (x, −y mod p), сумма которой с P равна O.
_Avoid_: обратная координата, обратный элемент поля

**Скалярное умножение kP**:
Групповая операция повторного сложения точки с учётом знака целого k; 0P = O.
_Avoid_: произведение двух точек

**Порядок точки ord(P)**:
Наименьшее положительное целое n, для которого nP = O; ord(O) = 1.
_Avoid_: число точек кривой

**Число точек кривой #E**:
Количество элементов группы E(Fp), включая O.
_Avoid_: порядок отдельной точки

**Циклическая подгруппа ⟨P⟩**:
Множество различных кратных P, включая O; её размер равен ord(P).

**Дискретный логарифм точки**:
Наименьшее неотрицательное k, удовлетворяющее Q = kP, если Q принадлежит ⟨P⟩.

**Учебный обмен ECDH**:
Демонстрация равенства a(bG) = b(aG) при заданных целых a и b; общий результат является точкой кривой.
