# Практическая работа № 2. Калькулятор на эллиптических кривых

## Условие

Преподавателем задано название «Калькулятор на эллиптических кривых» без дополнительных требований и варианта. Согласованная постановка: консольный учебный калькулятор над простым полем Fp с арифметикой точек, исследованием группы, демонстрацией ECDH и перебором дискретного логарифма.

## Реализация

Кривая: `y² = x³ + ax + b (mod p)`, простое `p > 3`, `4a³ + 27b² ≠ 0 (mod p)`.
Модуль — `u64`; коэффициенты, координаты на входе и скаляры — `i128`. Коэффициенты и координаты нормализуются по модулю p. Промежуточные произведения вычисляются в `u128`, без переполнения во всём диапазоне `u64`.

- `domain/field.rs`: модульная арифметика, обратный элемент через малую теорему Ферма, детерминированный Miller–Rabin для `u64`.
- `domain/curve.rs`: группа точек, double-and-add, перечисление точек, порядок, подгруппа, таблица, дискретный логарифм, учебный ECDH.
- `application/`: типизированные сценарии, логирование операций и формирование результатов.
- `presentation/`: разбор CLI через clap и печать результата. `main` инициализирует общий логгер.

Отдельных внешних портов и инфраструктурных адаптеров у калькулятора нет: он не читает ключи, файлы или сеть. Арифметика написана самостоятельно, новых библиотек для вычислений не добавлено.

Точка на бесконечности обозначается `O` (также принимается `inf`). Точка задаётся как `x,y` без пробелов либо одной строкой в кавычках. Ноль, противоположные точки, удвоение при `y=0` и отрицательные скаляры обработаны явно. Недопустимая точка отвергается даже при умножении на ноль.

## Как запустить

```bash
cargo build -p practice_02
just practice-02 --help
just practice-02 demo

# Кривая по умолчанию: p=17, a=2, b=2; G=(5,1), ord(G)=19
just practice-02 info
just practice-02 check 5,1
just practice-02 neg 5,1
just practice-02 add 5,1 6,3
just practice-02 sub 5,1 6,3
just practice-02 double 5,1
just practice-02 mul 7 5,1
just practice-02 mul -- -3 5,1
just practice-02 linear 2 5,1 3 6,3
just practice-02 inverse 2
just practice-02 points
just practice-02 count
just practice-02 order 5,1
just practice-02 subgroup 5,1
just practice-02 dlog 5,1 0,6
just practice-02 ecdh 5,1 5 7

# Своя кривая и компактная таблица группы из четырёх точек
just practice-02 --p 5 --a 1 --b 0 table
just practice-02 --p 5 --a 1 --b 0 double 0,0

# Без диагностических логов
RUST_LOG=off cargo run -p practice_02 -- add 5,1 6,3
```

`demo` всегда использует фиксированную демонстрационную кривую (17,2,2); остальные команды работают с параметрами `--p`, `--a`, `--b`.

## Входы и выходы

| Команда | Результат на кривой по умолчанию |
|---|---|
| `add 5,1 6,3` | `(10, 6)` |
| `double 5,1` | `(6, 3)` |
| `sub 5,1 6,3` | `(5, 16)` |
| `mul 7 5,1` | `(0, 6)` |
| `linear 2 5,1 3 6,3` | `(13, 7)` |
| `add 5,1 5,16` | `O` |
| `count` | `19`, включая `O` |
| `order 5,1` | `19` |
| `dlog 5,1 0,6` | `k=7` |
| `ecdh 5,1 5 7` | `A=(9,16)`, `B=(0,6)`, общая точка `(10,11)` |

Результат поступает в stdout, диагностические сообщения — в stderr. Успех имеет код 0, ошибка — ненулевой код. Для `check` непринадлежность точки является корректным результатом `false` с кодом 0. Ошибочный формат аргумента отвергает clap.

Полный перебор точек: `p ≤ 10 000`, таблица: не более 32 точек. Поиск порядка, подгруппы и дискретного логарифма ограничен 100 000 сложений. Исчерпание лимита — явная ошибка, а не утверждение, что решения нет. `dlog` возвращает наименьшее неотрицательное k; отсутствие решения устанавливается только после полного обхода подгруппы. Для `O` порядок равен 1.

ECDH демонстрирует математическое равенство общих точек. Скаляры заданы пользователем, должны удовлетворять `1 ≤ a,b < ord(G)`; общий результат `O` отвергается. Генерация случайных ключей, KDF, шифрование сообщений и постоянное время исполнения не реализованы; использовать этот учебный код для защиты реальных данных нельзя. Стандартные 256-битные кривые не входят в выбранный диапазон.

## Как протестировать

```bash
cargo test -p practice_02
just ci
```

Тесты проверяют ручную таблицу кратных G, все 6859 троек точек на E17(2,2) для ассоциативности, перечисление точек независимым двойным перебором на нескольких кривых, границу `u64`, псевдопростые числа, `i128::MIN`, свойства группы через proptest и все команды CLI, включая ошибки. Число тестов и результаты полного gate автоматически фиксируются при создании отчёта.

## Источники

- [Standards for Efficient Cryptography 1 (SEC 1), § 2.2.1](https://www.secg.org/sec1-v2.pdf): закон сложения и скалярное умножение.
- [RFC 6090, §§ 2–4](https://www.rfc-editor.org/rfc/rfc6090): арифметика поля, невырожденность и ECDH.
- [Наборы оснований детерминированного Miller–Rabin, Jim Sinclair](https://miller-rabin.appspot.com/): семь оснований для всего диапазона `u64`.
