ОПИСАНИЕ МЕТОДА СТЕГАНОГРАФИЧЕСКОГО СОКРЫТИЯ ОДНОГО БИТА В СТРОКЕ
Практическая работа №3. Вариант №11. Ковалев Д.П., ВКБ51.

1. ИДЕЯ
Всё множество осмысленных строк русского языка делится на два
непересекающихся подмножества Y и N по двум признакам: чётности количества
гласных букв в строке и длине первого слова.
  - ЧЁТНОЕ число гласных И первое слово длиннее 5 букв
    -> подмножество Y (бит = 1, ответ «ДА»);
  - во всех остальных случаях -> подмножество N (бит = 0, ответ «НЕТ»).

Гласные русского алфавита (учитываются в любом регистре):
    А Е Ё И О У Ы Э Ю Я

2. АЛГОРИТМ КЛАССИФИКАЦИИ (программа отвечает «ДА»/«НЕТ»)
  Вход:  строка S естественного языка.
  Шаг 1. Привести S к нижнему регистру.
  Шаг 2. Посчитать V — количество символов S, входящих в множество гласных.
  Шаг 3. Найти первое слово и посчитать L — количество букв в нём, не
         учитывая окружающие знаки препинания и дефис.
  Шаг 4. Если V mod 2 == 0 И L > 5 -> строка принадлежит Y, ответ «ДА».
         Иначе                     -> строка принадлежит N, ответ «НЕТ».
  Выход: «ДА» либо «НЕТ».

3. АЛГОРИТМ СОКРЫТИЯ БИТА (сторона отправителя)
  Чтобы передать бит b в строке:
  - для b=1 сформулировать строку с чётным числом гласных и первым словом
    длиннее пяти букв;
  - для b=0 нарушить хотя бы одно из этих условий;
  - при необходимости скорректировать чётность минимальной правкой, не
    меняющей смысл: заменить слово синонимом, добавить/убрать частицу или
    союз (напр. «и», «не»), что меняет число гласных на 1.

4. СВОЙСТВА МЕТОДА
  - Определён на всём множестве осмысленных строк: каждая строка однозначно
    проверяется по обоим условиям и попадает ровно в одно из подмножеств.
  - Устойчив к орфографическим ошибкам, не затрагивающим гласные.
  - Обратим и не требует ключа для чтения бита (ключом является сам метод).
  - Используются статистические параметры текста и абсолютное положение
    символов (пункты «a» и «c» условия).

5. ФОРМАТ ВВОДА/ВЫВОДА ПРОГРАММЫ
  Вход:  текстовый файл, одна строка = одна проверяемая строка.
  Выход: файл и экран. Строка результата:
  <ответ> \t <число гласных> \t <длина первого слова> \t <строка>.
