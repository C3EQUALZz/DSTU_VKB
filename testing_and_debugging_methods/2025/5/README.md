# Лабораторная 5

Произвести отладку путем трассировки с использованием встроенного логгера import logging из Python.

Берется любой небольшой проект / скрипт, где есть соотв. ошибка.
Исследуем данный скрипт через логи и анализируем проблемы. Потом благодаря логам понимаем, где проблема и соотв. правим.
Нужно составить отчет.

## Выполненная работа

Подготовлен учебный скрипт расчёта заказа. В версии `legacy` намеренно
внесена ошибка: `int(10 / 100)` обнуляет коэффициент скидки. Трассировка
через стандартный `logging` показывает первое неверное значение. Исправленная
версия сохраняет дробную часть с помощью `Decimal`.

Для заказа из `data/order.json` сумма товаров составляет 4000 ₽,
скидка — 10%, правильный итог — 3600 ₽. Исходная версия возвращает 4000 ₽.

### Запуск

Команды выполняются из каталога `testing_and_debugging_methods/2025/5`.
Сам расчёт использует только стандартную библиотеку Python 3.12+.

```bash
uv sync --all-groups
export PYTHONPATH=src

# Ошибка воспроизводится; с --check ожидается код завершения 1.
.venv/bin/python -m fifth_laboratory \
  --version legacy --log-level DEBUG --check

# Исправленный расчёт; ожидается код завершения 0.
.venv/bin/python -m fifth_laboratory \
  --version fixed --log-level DEBUG \
  --log-file report_assets/logs/fixed.log --check

# Полный набор: 19 тестовых случаев.
.venv/bin/python -m pytest
```

`--version fixed` и `--log-level INFO` используются по умолчанию.
`--input` позволяет указать другой JSON того же формата.
`--check` сравнивает итог с независимым полем `expected_total`.
Код 2 означает ошибку чтения или обработки входных данных.
Строковые цены и проценты в JSON сохраняют точные десятичные значения.

### Повторная сборка отчёта

```bash
.venv/bin/python scripts/capture_evidence.py
.venv/bin/python scripts/build_report.py
osascript scripts/export_pdf.applescript \
  "$PWD/../docs/reports/lab_05/Ковалев Д.П. ВКБ43 5 лаба.docx" \
  "$PWD/../docs/reports/lab_05/Ковалев Д.П. ВКБ43 5 лаба.pdf"
```

Скрипт `capture_evidence.py` восстанавливает локальные журналы и manifest.json,
а иллюстрации сохраняет в общую папку `../docs/screenshots/lab_05/`.
Каталог `report_assets/` используется только для локальных служебных файлов.

Иллюстрации создаются установленным CLI `freeze` и CairoSVG; на данном Mac
используется библиотека Cairo из Homebrew. Скрипт исправляет отсутствующую
область отсечения в SVG Freeze 0.2.2 и убирает неверно размещённые фоновые
плашки diff, сохраняя цвет строк и текст вывода. Для иллюстрации
падающего теста создаётся временный снимок исходников с прежней строкой
расчёта; рабочие файлы не изменяются.

Генератор DOCX использует общий шаблон `../scripts/report_builder.py` и логотип
`../docs/assets/dstu_logo.png`. Для экспорта PDF необходим установленный
Microsoft Word и разрешение macOS на управление им через AppleScript.
