### Запуск и тестирование

Из каталога лабораторной №6:

```bash
uv sync --all-groups

# Исходная версия: CHECK: FAIL, код завершения 1.
.venv/bin/python demo.py --version legacy --check

# Исправленная версия: CHECK: PASS, код завершения 0.
.venv/bin/python demo.py --version fixed --check

# 12 тестовых случаев.
.venv/bin/python -m pytest
```

Для расчёта достаточно стандартной библиотеки Python 3.12+.
`--version` выбирает реализацию; по умолчанию используется `legacy`
для демонстрации отладки. `--check` сравнивает результат с независимым эталоном.

### Отладка через pdb

```bash
.venv/bin/python -m pdb demo.py --version legacy
```

Внутри отладчика вводить команды по одной:

```text
b average_legacy.py:11
c
p values
p (index, total, len(values))
p values[-1]
p sum(values)
p total / len(values)
where
q
```

Перед `return` исходная версия показывает `(2, 60.0, 4)`.
Для пошагового исследования поставить точку `b average_legacy.py:9`, выполнить
`c`, затем `display total`, `n`, `p index`, `n`, `p total`.
После первого сложения `total` меняется с 0.0 на 10.0.

Для исправленной версии запустить `--version fixed`, поставить
`b average.py:11` и выполнить те же проверки. Состояние перед возвратом:
`(3, 100.0, 4)`, среднее — 25.0. Команда `c` продолжает выполнение,
`q` закрывает сессию после предлагаемого pdb повторного запуска.

### Отладка через PyCharm

1. Открыть каталог `6` в PyCharm и выбрать интерпретатор `6/.venv/bin/python`.
2. Создать конфигурацию Python: скрипт `demo.py`, параметры
   `--version legacy --check`, рабочий каталог `6`.
3. Поставить точки останова в `average_legacy.py` на строках 10 и 11.
4. Добавить Watches: `len(values)`, `sum(values)`,
   `list(range(len(values) - 1))`, `values[-1]`.
5. Запустить **Debug**, выполнить **Step Over**, затем **Resume Program**
   до точки перед `return`. Проверить `index=2`, `total=60.0`.
6. Создать аналогичную конфигурацию с `--version fixed --check`,
   поставить точку на строке 11 `average.py`. Проверить значения
   `index=3`, `total=100.0`, затем продолжить до `CHECK: PASS`.

В отчёте использованы настоящие снимки PyCharm 2026.2.2 с Python 3.14.3.
Строка остановки ещё не выполнена: это нужно учитывать при чтении переменных.

### Сборка иллюстраций и отчёта

```bash
.venv/bin/python scripts/capture_evidence.py --stage before
.venv/bin/python scripts/capture_evidence.py --stage after
.venv/bin/python scripts/build_report.py
osascript ../5/scripts/export_pdf.applescript \
  "$PWD/../docs/reports/lab_06/Ковалев Д.П. ВКБ43 6 лаба.docx" \
  "$PWD/../docs/reports/lab_06/Ковалев Д.П. ВКБ43 6 лаба.pdf"
```

Для иллюстраций консоли используются установленный `freeze` и CairoSVG
с библиотекой Cairo из Homebrew. Снимки PyCharm выполняются в самой IDE:
скрипт `capture_evidence.py` их не подделывает и не генерирует.
Для повторного протокола падающего теста создаётся изолированный временный
снимок исходников с прежней строкой цикла; рабочие файлы не меняются.

Оформление DOCX использует общий `../scripts/report_builder.py` и логотип ДГТУ.
Экспорт PDF выполняется через установленный Microsoft Word.
